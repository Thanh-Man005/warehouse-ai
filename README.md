## 🛠️ Cài đặt ứng dụng (Dành cho máy mới)

### Bước 1: Tải Python
Vào [python.org/downloads](https://www.python.org/downloads/) → Tải **Python 3.11** và cài đặt.
> **Lưu ý quan trọng:** Lúc cài đặt nhớ tích chọn ô **"Add Python to PATH"**.

### Bước 2: Mở cửa sổ lệnh (CMD)
- Bấm tổ hợp phím `Win + R` → Gõ `cmd` → Bấm `Enter`.
